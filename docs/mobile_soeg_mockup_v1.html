Søg — designvalg

Aktivering

  • Tap på lup-ikon i top-tabs → top-tabs slides ud, søg-row slides ind
  • Søgefelt får autofokus → tastatur popper op automatisk
  • Tilbage-pil eller "Annuller" lukker søg og returnerer til sidste tab (Nye/I dag/…)

Søgefeltet

  • Placeholder: "Søg bonnummer, kunde, firma, telefon…"
  • Live-søg med 300ms debounce — ikke kald pr. tastetryk
  • ×-knap rydder feltet og vises kun når der er tekst
  • Match-highlight: gul baggrund på matchende tekst i resultatet

Hvad søges der i (backend)

  • bons.bon_number — eksakt eller prefix-match
  • customers.first_name + last_name — LIKE %q%
  • customers.company_name — LIKE %q%
  • customers.phone — kun hvis q er rent tal
  • Rent tal ≥ 4 cifre = bonnummer-prioritet, derefter telefon
  • Backend: udvid eksisterende GET /api/bons?q= hvis q ikke allerede dækker alle felter
