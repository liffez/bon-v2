Designvalg
Hvad mockup'en bygger på.

Én knap, to handlinger

"Kopiér og åbn taxa.nu" gør begge dele i ét klik. Bekræftelse vises som tekst under knappen. Knappen forbliver aktiv — ændrer label til "Kopiér igen" så bruger kan re-kopiére hvis clipboard er overskrevet.

Read-only preview som default

Mørk preview = system-genereret tekst. "Rediger"-knap øverst aktiverer textarea-mode. Bruger ser tydeligt hvad der er system vs. egen redigering.

Manglende felter markeres

Tomme pladsholdere vises som [mangler] i previewen — ikke som tom plads. Plus gul advarsel-boks øverst der lister hvilke felter. Blokerer ikke booking.

Ref-felt altid synligt

Ingen progressive disclosure — alt vises fra start. "Marker som booket" er disabled indtil ref er udfyldt ELLER bruger trykker "Spring over".

Multi-stop håndteres i template

Multi-stop ture aggregerer pakke-info, lister stops nummereret, og viser kontakt pr. bon. Office kan tilpasse template i settings hvis taxa-firmaet vil have noget specifikt.

"Spring over" er sekundær handling

Diskret subtle-knap. Tur markeres in_progress og dukker op i "Afventer booking"-banner i listview. Ikke tabt — bare udskudt.
