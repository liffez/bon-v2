PR 1's data-logik er allerede bygget — dette er kun UX-laget.

Interaktions-princip: omkostning følger hyppighed, ikke konsekvens-frygt. 1 tryk på kortet til hyppige arbejdsskridt (✓ godkend · ⏭ spring over) — med billig Fortryd som modstykke. 2 tryk (⋯) til beslutninger der ændrer stamdata (Skal ikke tjekkes = rydder HverDag · Udgået = 0 + deaktivér), hvor friktionen er pointen.
