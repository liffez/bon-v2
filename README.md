# Bon v2

Catering management system — fire zoner: Kitchen, Office, Logistik, Settings.

## Kom i gang

```bash
npm install
npm run dev
```

Åbn http://localhost:3000

## Zoner

| Zone     | URL          | Beskrivelse                  |
|----------|--------------|------------------------------|
| Kitchen  | /kitchen/    | Tablet-first, touch-venlig   |
| Office   | /office/     | Desktop, informationstæt SPA |
| Settings | /settings/   | Kontrolpanel                 |

## Teknologi

- **Frontend:** Vanilla JS + Vue.js, Vanilla CSS med tokens
- **Backend:** Node.js / Express
- **Database:** SQLite
- **Realtid:** SSE (Server-Sent Events)
